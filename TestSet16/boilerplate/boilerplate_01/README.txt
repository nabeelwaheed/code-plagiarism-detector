Boilerplate 01: CLI and file helper starter package

Contents:
- include/starter_args.h: common argument parsing struct and function prototypes
- include/starter_io.h: file loading and line splitting helper prototypes
- src/starter_args.c: option parsing for -i/-o/-v flags
- src/starter_io.c: file read/write and mutable line split helpers
- src/starter_main.c: minimal demo program using starter utilities

This package is intended as instructor-provided starter code.
It uses plain C11 and no external dependencies.
