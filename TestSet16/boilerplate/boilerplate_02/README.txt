Boilerplate 02: Menu and record helper starter package

Contents:
- include/menu_framework.h: simple menu abstraction for CLI loops
- include/record_utils.h: parsing and string normalization helpers
- src/menu_framework.c: reusable menu rendering and dispatch logic
- src/record_utils.c: utility functions for numeric parsing and token copy
- src/sample_driver.c: minimal menu-driven demo program

This package is intended as instructor-provided starter code.
It uses plain C11 and no external dependencies.
